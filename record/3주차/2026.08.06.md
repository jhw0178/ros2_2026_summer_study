### 1. 필터링
#### 4가지의 블러 형태를 배움
##### 1-1. 블러 필터
##### (1) blur(), boxFilter()
    - 4가지 형태의 블러 방법 중 가장 기초적인 방법
##### (1) 예시)
    def main():
        file_path = Path(__file__).parent
        file_path = file_path / "data/lena.jpg"
        img: np.ndarray = cv2.imread(str(file_path))   # type: ignore
        # boxfilter
        dst1 = cv2.boxFilter(img, ddepth=-1, ksize=(11, 11))    # k는 홀수로만
        # blur
        dst2 = cv2.blur(img, (11, 11))
        # filter 2D
        kernel = np.ones((11, 11)) / 11
        dst3 = cv2.filter2D(img, ddepth=-1, kernel=kernel)
        
        # 실행시 창 띄우기
        cv2.imshow("img", img)
        cv2.imshow("box11", dst1)
        cv2.imshow("blur", dst2)
        cv2.imshow("filter2D", dst3)
        cv2.waitKey()
        cv2.destroyAllWindows()
##### (2) GaussianBlur()
    - Kernel 사용은 같지만, Gaussian 함수를 이용해서 블러를 적용
##### (3) medianBlur()
    - 주위 kernel 의 픽셀값을 정렬해서 중간값을 사용
##### (4) bilateralFilter()
    - 경계선을 유지하면서 Gaussian Blur처리를 해주는 방법
##### (2),(3),(4) 예시)
    def main():
        file_path = Path(__file__).parent
        file_path = str(file_path / "data/lena.jpg")
        img: np.ndarray = cv2.imread(file_path)  # type: ignore
        # Gaussian 사람이은 함수더라도 대문자를 쓴다.
        dst1 = cv2.GaussianBlur(img, (11, 11), 3)
        dst2 = cv2.GaussianBlur(img, (11, 11), 10)
        dst3 = cv2.bilateralFilter(img, -1, 30, 30)  # bilateral 노이즈 없애면서 경계강화!!
        cv2.imshow("img", img)
        cv2.imshow("Gaussian", dst1)
        cv2.imshow("Gaussian10", dst2)
        cv2.imshow("bilateral", dst3)
        cv2.waitKey()
        cv2.destroyAllWindows()
##### 1-2. 미분 필터
##### 공간 영역의 개념과 회선
##### 차분에 의한 미분 연산
    - X 축 방향 또는 y 축 방향으로 전후 혹은 좌우 의 픽셀 데이터를 이용하여 영상의 변화값을 두 픽셀의 차이로 구함 
    - 회선(convolution)을 위와 같은 마스크를 사용하면 각각의 편미분 값을 구할 수 있음
##### 기울기의 계산
    - 각 픽셀의 미분 값에 x, y 값의 크기를 더하면 변화의 크기를 계산
    - 기울기를 계산하면 엣지의 방향을 구함
##### (1) 미분 필터 - 소벨 마스크
##### 1차 미분 필터
    - Sobel() 연산을 사용하면 gx, gy 값을 구할 수 있음
    - Ksize = 3 을 사용
    - 수직수평과 대각성 방향의 엣지를 검출 할 수 있음
    - . Cv2.filter2D() 를 사용하여 마스크를 직접 계산하여 구할 수 도 있음
##### (2) 미분 필터 - 가우시안 마스크
##### 2차 미분 필터
    - F(x,y) 의 라플라시안2파 편미분의 합으로 엣지 화소는 필터링 영상에서 부호가 (+,-), (-,+)로 바뀌어 zero-crossing 이라고 함 
    - ∇²f(x, y) = f(x-1, y) + f(x+1, y) + f(x, y-1) + f(x, y+1) - 4·f(x, y)
