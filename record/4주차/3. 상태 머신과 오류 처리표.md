# 3. 상태 머신과 오류 처리

## 3.1 캘리브레이션 노드 상태 머신

```text
┌─────────────────┐
│     START       │
└────────┬────────┘
         ▼
┌─────────────────┐
│  CAMERA_INIT    │
└────────┬────────┘
         │
     실패│
         ▼
   RuntimeError
      종료

         │ 성공
         ▼
┌─────────────────┐
│   COLLECTING    │
│   마커 수집      │
└────────┬────────┘
         │
         │ 매 프레임
         │
         ├─ ArUco 검출
         ├─ ID 1~4 위치 저장
         └─ 0.5 s 미검출 마커 제거
         │
         │ ID 1~4 동시 확보
         ▼
┌─────────────────┐
│     LOCKED      │
│  변환 서비스 중  │
└────────┬────────┘
         │
         ├─ H 계산 후 고정
         ├─ detections 수신
         ├─ 좌표 변환
         ├─ 거리 정렬
         ├─ nearest 발행
         └─ 마우스 클릭 좌표 검증
         │
         │ 'r'
         └──────────────► COLLECTING

         │ 'q'
         │ 카메라 read 실패
         ▼
       종료
```

## 3.2 검출 노드 파이프라인 상태

각 모델(`paper` / `pet` / `can`)은 독립적으로 동작한다.

```text
IDLE
 │
 │ 최신 프레임 존재
 │ future == None
 ▼
INFERRING
 │
 │ future.done()
 ▼
결과 수거
 │
 ├─ 정상 → 결과 저장
 └─ 예외 → 빈 목록
 │
 ▼
IDLE
```

30 Hz 타이머에서는 다음 작업을 수행한다.

```text
1. 완료된 Future 결과 수거
2. idle 상태인 모델에 최신 프레임 제출
3. 결과 시각화
4. JSON 발행
```

## 3.3 Pick & Place 시퀀스 상태 머신

```text
┌──────────────┐
│   WAIT_CMD   │
└──────┬───────┘
       │ Enter 입력
       ▼
┌──────────────┐
│  GET_TARGET  │
└──────┬───────┘
       │
       ├─ 목표 없음
       ├─ 2 s 초과
       └─ 작업영역 밖
             │
             ▼
          warn 후
        WAIT_CMD 복귀

       │ 정상 목표
       ▼
 거리 기반 좌표 보정

[S1] GRIPPER_OPEN
     position = 0.019 m

[S2a] 정면 안전 자세 상승
      joint1 = 0
      비행 자세

[S2b] 공중 회전 → 물체 방향
      joint1 = atan2(y, x)

[S2c] 물체 상공 이동
      IK(x, y, Z_SAFE=0.30)

[S3] 하강
     IK(x, y, PICK_Z[type])

[S4] GRIPPER_HOLD
     position = 0.003 m
     ← 파지

[S5] +5 cm 리프트
     IK(x, y, PICK_Z + 0.05)

[S6] 안전 비행 자세 상승
     물체를 든 채 팔 접음

[S7] 공중 회전 → 분류함 방향
     joint1 = atan2(bin_y, bin_x)

[S8] 분류함 하강
     IK(bin_x, bin_y, 0.05)

[S9] GRIPPER_OPEN
     ← 배치

[S10] 안전 자세 상승

[S11] 공중 회전 → 정면 복귀
      joint1 = 0

[S12] HOME
      [0, -1.05, 0.35, 0.70]

       │
       └──────────────► WAIT_CMD
```

> S1~S10 어느 단계에서든 Action 서버 미응답 또는 실패가 발생하면 시퀀스를 중단하고 `WAIT_CMD`로 복귀한다.

## 3.4 오류 처리표

### 3.4.1 `aruco_homography_calibration`

| 오류                   | 조건                        | 처리                   | 대응                      |
| -------------------- | ------------------------- | -------------------- | ----------------------- |
| 카메라 열기 실패            | `cap.isOpened() == False` | RuntimeError → 노드 종료 | 장치 경로/GStreamer 플러그인 확인 |
| 프레임 read 실패          | `ret == False`            | 에러 로그 후 루프 종료        | 케이블/전원 확인               |
| 마커 순간 미검출            | 검출 목록에 없음                 | 0.5 s간 이전 위치 유지      | 자동                      |
| 마커 장기 미검출            | hold 시간 초과                | 후보에서 제거, 미LOCK 상태 유지 | 마커 재노출                  |
| 캘리브레이션 오염            | 마커 이동 등                   | H 리셋 필요              | `r` 키로 재수집              |
| Detection JSON 파싱 실패 | `JSONDecodeError`         | 에러 로그, 메시지 폐기        | 다음 메시지 자동 처리            |
| 좌표 필드 결손             | `KeyError` 등              | 해당 객체만 skip          | 자동                      |
| 미지원 type             | can/pet/paper 외           | 해당 객체 필터링            | -                       |
| H 미계산 상태 클릭          | `H is None`               | `NOT READY` 출력       | 마커 인식 후 재시도             |
| H 역행렬 불가             | `LinAlgError`             | 작업영역 표시 생략           | reset 후 재캘리브레이션         |
| Image 발행 예외          | cv_bridge 오류              | 에러 로그, 해당 프레임 skip   | 자동                      |

### 3.4.2 `waste_detector`

| 오류             | 조건                   | 처리                      | 대응                            |
| -------------- | -------------------- | ----------------------- | ----------------------------- |
| API Key 미설정    | 환경변수 없음              | RuntimeError + 설정 명령 안내 | `export ROBOFLOW_API_KEY=...` |
| 모델 로딩 실패       | `get_model` 예외       | 기동 실패                   | Model ID/네트워크 확인              |
| 인코딩 불일치        | `encoding != 'bgr8'` | 에러 로그, 프레임 폐기           | 발행측 확인                        |
| Image 버퍼 변환 실패 | reshape 예외           | 에러 로그, 프레임 폐기           | 자동                            |
| 추론 예외          | 네트워크 등               | 해당 모델만 빈 결과 반환          | 다음 주기 자동 재시도                  |
| Future 결과 예외   | `future.result()` 예외 | 해당 모델 결과 빈 목록           | 자동                            |
| 낮은 confidence  | threshold 미달         | 해당 검출 제외                | -                             |

### 3.4.3 `waste_pick_node`

| 오류            | 조건                        | 처리               | 대응          |
| ------------- | ------------------------- | ---------------- | ----------- |
| 목표 없음         | target 필드 None            | warn 후 명령 대기     | 물체 배치/인식 확인 |
| 목표 stale      | 수신 후 2.0 s 초과             | 목표 무효 처리         | 새 목표 수신     |
| 작업영역 밖        | X∉[0,0.4] 또는 Y∉[-0.2,0.2] | callback에서 저장 거부 | 물체 재배치      |
| 분류 위치 미설정     | `BIN_POSES` 없음            | 에러 로그, 중단        | 좌표 등록       |
| Action 서버 미응답 | `wait_for_server` 2 s 초과  | False → 시퀀스 중단   | 컨트롤러 재기동    |
| 목표 JSON 파싱 실패 | JSON 예외                   | 메시지 폐기           | 자동          |

## 3.5 시스템 수준 알려진 한계 및 개선 권장 사항

|  # | 한계                      | 문제                                                      | 개선 방향                                                        |
| -: | ----------------------- | ------------------------------------------------------- | ------------------------------------------------------------ |
|  1 | **Action 결과 미확인**       | `send_goal_async` + sleep 방식으로 궤적 실패 및 goal 거부를 감지하지 못함 | `spin_until_future_complete`로 goal 수락·result·error_code 검사   |
|  2 | **파지 성공 여부 미검증**        | 빈 그리퍼로 S5~S9 진행 가능                                      | GripperCommand result의 `reached_goal`/position 검사 및 실패 시 재시도 |
|  3 | **근사 IK의 자세·범위 한계**     | 작업영역 가장자리 및 paper의 `z=-0.07`에서 오차 증가                    | 해석적 IK로 교체 또는 구간별 보정 테이블 확대                                  |
|  4 | **Homography 평면 가정**    | 높이가 큰 물체(세운 페트병)는 밑점에서도 잔여 오차 발생                        | 물체별 높이 오프셋 또는 카메라 자세 보정                                      |
|  5 | **실행 중 목표 갱신 미반영**      | 시퀀스 시작 시점 좌표로 고정                                        | 시작 직전 재조회 또는 하강 직전 1회 재확인                                    |
|  6 | **BIN 좌표의 근사 IK 범위 문제** | `(-0.18, ±0.13)`은 근사 IK 학습 범위 밖(후방)                     | 분류함 자세를 관절각으로 직접 티칭                                          |
|  7 | **캘리브레이션 노드 기능 집중**     | GUI·카메라·좌표 변환이 한 노드에 집중되어 헤드리스 환경 실행 불가                 | 표시 기능 분리 및 GUI on/off 파라미터화                                  |
