# 8. 향후 개선 방향

## 8.1 Action 결과 검증

현재:

```python
send_goal_async(...)
time.sleep(...)
```

개선:

```text
Goal 전송
  ↓
Goal 수락 여부 확인
  ↓
Result 대기
  ↓
error_code 확인
  ↓
성공 → 다음 단계
실패 → 시퀀스 중단 / 재시도
```

이를 통해 로봇이 실제로 목표 관절 위치에 도달했는지 확인할 수 있다.

---

## 8.2 파지 성공 검증

현재는 그리퍼를 닫은 후 실제 물체가 잡혔는지 확인하지 않는다.

개선 방향:

```text
GripperCommand
      ↓
reached_goal 확인
      ↓
position 확인
      ↓
파지 성공 판단
      ↓
실패 시 재시도 또는 시퀀스 중단
```

---

## 8.3 정밀 IK 적용

현재 근사 IK:

```text
simple_ik_solver()
        ↓
거리 기반 보정
        ↓
실측 튜닝
```

향후에는 다음 구조를 고려할 수 있다.

```text
URDF / Robot Model
        ↓
정확한 Forward Kinematics
        ↓
Analytical 또는 Numerical IK
        ↓
Joint Limit 검사
        ↓
Collision 검사
        ↓
Trajectory 생성
```

---

## 8.4 Homography 보완

Homography는 작업판 평면에 대해서는 효과적이지만 높이가 큰 물체에는 오차가 발생할 수 있다.

향후 개선 방향:

* 물체별 높이 오프셋 적용
* 카메라 외부 파라미터 추정
* Camera Calibration + `solvePnP`
* RGB-D 카메라를 이용한 3D 좌표 추정
* 물체별 grasp point 학습

---

## 8.5 GUI 분리

현재 `aruco_homography_calibration` 노드에 카메라, GUI, ArUco, Homography 및 좌표 변환 기능이 집중되어 있다.

향후에는 다음과 같이 분리할 수 있다.

```text
Camera Node
    ↓
Image Topic
    ↓
ArUco Calibration Node
    ↓
Homography / Calibration
    ↓
Detector Node
    ↓
Robot Control Node
```

GUI 기능은 별도의 Visualization Node로 분리하여 Headless 환경에서도 전체 시스템을 실행할 수 있도록 개선한다.

# 9. 프로젝트 핵심 요약

본 프로젝트는 USB 카메라와 딥러닝 기반 객체 인식을 이용하여 **캔, PET, 종이 쓰레기를 자동 분류하는 비전 기반 Pick & Place 시스템**이다.

전체 시스템은 다음 3개의 ROS 2 노드로 구성된다.

```text
① aruco_homography_calibration
   ├─ 카메라 캡처
   ├─ ArUco 검출
   ├─ Homography 계산
   ├─ 픽셀 → 로봇 좌표 변환
   └─ 최근접 목표 선정

② waste_detector
   ├─ 최신 카메라 프레임 수신
   ├─ Paper 모델
   ├─ PET 모델
   ├─ Can 모델
   ├─ 3개 모델 병렬 추론
   └─ bbox 밑변 중앙점 발행

③ waste_pick_node
   ├─ 최근접 목표 수신
   ├─ 목표 신선도 검사
   ├─ 작업영역 검사
   ├─ 거리 기반 좌표 보정
   ├─ 근사 IK
   └─ 12단계 Pick & Place
```

핵심 설계는 다음과 같다.

1. **ArUco + Homography 기반 자동 좌표 변환**
2. **3개 딥러닝 모델의 병렬 추론**
3. **bbox 중심이 아닌 밑변 중앙점을 이용한 평면 기준점 추출**
4. **원점과의 거리 기반 최근접 객체 우선 처리**
5. **거리 기반 선형 좌표 보정**
6. **경험적 근사 IK를 이용한 단순한 로봇 제어**
7. **안전 비행 자세와 공중 회전을 이용한 충돌 회피**
8. **Enter 1회로 가장 가까운 객체 1개를 처리하는 Pick & Place**
9. **ROS 2 Topic / Action 기반 노드 간 분산 처리**
10. **향후 Action 결과 및 파지 성공 검증을 통한 안정성 개선**
