### 2. USBIPD 설치
##### 2-1. 관리자 권한으로 PowerShell 또는 Windows 터미널을 실행 후, winget 패키지 관리자를 사용하여 usbipd-win 을 설치
    $ winget install --interactive --exact dorssel.usbipd-win
##### 2-2. 현재 연결된 USB 장치 목록과 BUS ID를 확인
    $ usbipd list
##### 2-3. USB 장치 공유 (PowerShell)
    # 예시: BUSID가 4-2인 장치를 공유
    usbipd bind --busid 4-2
    : -force 옵션을 추가하면 다른 드라이버가 사용 중이어도 강제로 바인딩할 수 있음
##### 2-4. USB 장치 WSL에 연결 (PowerShell)
    $  usbipd attach --wsl --busid 4-2
##### 2-5. WSL 에서 장치 확인 및 사용
    $ lsusb : lsusb 명령어를 실행하여 USB 장치가 정상적으로 인식되었는지 확인
##### 2-6. 아두이노와 같은 시리얼 통신 장치는 /dev/ 디렉토리에 ttyUSB0 또는 ttyACM0 과 같은 이름으로 나타남
    $ ls -l /dev/tty*

### 3. 로보틱스 독스
#### https://docs.robotis.com/docs/systems/openmanipulator_x/quick_start_guide/
    $ sudo usermod -aG dialout $USER
##### 3-1. open_manipulator_ws 생성
    $ cd ~/ros2_2026_summer_study
    $ mkdir -p open_manipulator_ws
    $ cd open_manipulator_ws
##### 3-2. git clone
    $ git clone -b jazzy https://github.com/ROBOTIS-GIT/DynamixelSDK.git && \
      git clone -b jazzy https://github.com/ROBOTIS-GIT/dynamixel_interfaces.git && \
      git clone -b jazzy https://github.com/ROBOTIS-GIT/dynamixel_hardware_interface.git && \
      git clone -b jazzy https://github.com/ROBOTIS-GIT/open_manipulator.git
##### 3-3. Install ROS2 Dependencies
    $ cd ~/ros2_2026_summer_study/open_manipulator_ws
    $ sudo rosdep init
    $ rosdep update
    $ rosdep install --from-paths src -y --ignore-src
##### 3-4. Build Packages
    $ colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release
    여기서, 11번째 package에서 막혀 --packages-select로 하나하나 다운 받음
    하지만 open_manipulator_gui는 시도해도 안 돼서 포기함.
##### 3-5. bashrc 설정 추가
    source ~/ros2_2026_summer_study/open_manipulator_ws/install/setup.bash 를 추가하여 소스 설정
